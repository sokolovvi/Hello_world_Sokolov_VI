Основы веб-разработки

Этот курс знакомит с фундаментальными технологиями создания современных веб-сайтов и приложений. Вы научитесь верстать страницы и программировать на JavaScript.

Введение в HTML

Изучите базовые теги разметки, атрибуты и принципы построения семантической структуры документа. Научитесь создавать формы, таблицы и списки.

Семантические теги

Теги header, nav, article, section, aside и footer помогают сделать код понятным для поисковых систем и вспомогательных технологий.

Работа с мультимедиа

Добавление изображений, аудио и видео с помощью тегов img, audio и video. Настройка параметров воспроизведения и форматов.

Стилизация с помощью CSS

CSS управляет внешним видом страниц: цвета, шрифты, расположение элементов, адаптивность. Освойте селекторы, свойства и модели позиционирования.

Flexbox и Grid

Современные методы создания гибких макетов без использования float и таблиц. Верстка резиновых и адаптивных интерфейсов.

Анимации и переходы

Плавные изменения свойств элементов, ключевые кадры, трансформации. Оживите интерфейс без JavaScript
